# Blended Krewe Creations website starter

Static responsive pre-launch storefront for BlendedKrewe.com.

## Deploy to Vercel
1. Create a GitHub repository (for example `blended-krewe-creations`).
2. Upload the contents of this folder to the repository root.
3. In Vercel, import that repository as a new project.
4. Framework preset: **Other** / static site. No build command needed.
5. Add `blendedkrewe.com` and `www.blendedkrewe.com` to the project Domains settings.

## Current state
- Pre-launch only; no checkout or untested products are represented as available.
- Concept renders are labeled "Design Preview".
- Contact goes to `orders@blendedkrewe.com`.
- Once products are printed/tested, replace concept images with real product photography and enable checkout/payment options.
